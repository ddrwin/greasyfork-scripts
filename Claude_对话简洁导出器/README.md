# Claude 对话简洁导出器（MD+HTML）

在 claude.ai 对话页面添加导出按钮，支持**两种模式**、**两种格式**——共四种导出方式。

**版本：** v1.1.0

## 两种模式

### 简洁版（Clean）

只保留对话核心内容，适合快速阅读和分享：

- ✅ **用户与 Claude 的对话文本**
- ✅ **Claude 的思考过程（thinking）**
- ❌ **过滤工具调用**（tool_use / tool_result）
- ❌ **过滤上传文档原文和附件内容**

### 完整版（Full）

保留所有内容，但每个非对话块都带**清晰的视觉容器**（与 thinking 区块视觉效果一致）：

- ✅ **对话文本**
- ✅ **思考过程**（默认展开）
- ✅ **工具调用**（搜索、代码执行、widget、artifact 等）— 各自带不同图标和边框颜色
- ✅ **工具执行结果** — 搜索结果卡片化、代码输出分组
- ✅ **上传文档和附件原文** — 可折叠的引用文档容器
- ✅ **图片** — 内联显示

每个块类型有不同的边框颜色和图标：

| 块类型 | 图标 | 视觉容器 |
|--------|------|---------|
| 思考过程 | 💭 | 米黄底 + 暖灰边框 |
| 工具调用 | 🔧/🔍/⚡/📊 | 浅灰底 + 深灰边框 |
| 工具结果 | 📋 | 浅褐底 + 灰色边框 |
| 搜索结果 | 🔍 | 浅蓝底 + 蓝灰边框 |
| 代码执行 | ⚡ | 浅绿底 + 绿灰边框 |
| 引用文档 | 📄 | 浅紫底 + 紫灰边框 |
| 上传文件 | 📎/🖼️ | 浅褐底 + 褐灰边框 |

## 两种格式

| 格式 | 特点 |
|------|------|
| **Markdown** | 纯文本，可用 `>` 引用块分节，适合 Obsidian/VS Code/Git 阅读 |
| **HTML** | 自包含文件，语法高亮、暗色/亮色切换、全部展开/折叠、"复制代码"按钮、Artifact 代码/预览切换 |

## 使用方法

1. 打开 Claude.ai 任意对话页面
2. 右下角橙色导出按钮
3. 点击展开菜单，选择：
   - **简洁版 → Markdown / HTML**
   - **完整版 → Markdown / HTML**
4. 文件自动下载

## 安装

1. 确保已安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 安装链接：`Claude 对话简洁导出器（MD+HTML） V1.1.0 (2026.06.11).user.js`
3. Tampermonkey 自动识别并提示安装

或手动复制到 Tampermonkey 新建脚本中。

## 实现

- 数据来源：Claude 官方 API（`/api/organizations/.../chat_conversations/...`）
- 数据不经过第三方，仅从 Claude 拉取后在浏览器本地生成文件
- 基于 [Claude Chat Exporter](https://greasyfork.org/scripts/571748)（midasgao）的 API 架构改进
