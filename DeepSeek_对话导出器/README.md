# DeepSeek 对话导出器 | DeepSeek Conversation Exporter Plus

优雅导出 DeepSeek 对话记录，支持 JSON 和 Markdown 格式。

**版本：** v0.0.9

## 功能

- 导出 DeepSeek 对话为 JSON 格式
- 导出 DeepSeek 对话为 Markdown 格式
- 适配 V4 网页版（专家/快速模式、深度搜索、多段思考链）

## 目录结构

```
DeepSeek_对话导出器/
├── DeepSeek 对话导出器.user.js    ← 主脚本
└── archive/                       ← 历史版本存档
```
