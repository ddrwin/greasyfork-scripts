# SingleFile 自动展开助手

在 SingleFile 保存前自动展开网页折叠区，确保保存的 HTML 内容完整。

**版本：** v1.0

## 功能

- 自动展开 100vh 折叠区
- 展开 grid 折叠元素
- 展开 overflow hidden 区域
- 确保保存内容完整，方便后续转 PDF

## 目录结构

```
SingleFile_自动展开助手/
├── SingleFile 自动展开助手.user.js    ← 主脚本
└── archive/                          ← 历史版本存档
```
