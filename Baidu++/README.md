# Baidu++

为百度搜索结果页添加多引擎搜索、自动翻页、去广告。

**版本：** v2.2

## 功能

- 百度搜索结果页添加软件、网盘、财经、社交问答、Google、Bing 搜索按钮
- 一键跳转到 Google/Bing
- Google 搜索结果页添加百度/Bing 搜索框
- Bing 搜索结果页添加百度/Google 搜索框
- 支持各搜索引擎自动翻页（触发距离 2000px）
- 去除百度结果页广告和右边栏
- 虎嗅网模块增强：URL 带 `#q=关键词` 时优先匹配历史关键词
- 新浪搜索自动翻页
