# 极简划词搜索

超小尺寸悬浮工具栏，支持划词搜索、复制、打开链接、拖拽保存、关键词高亮。

**版本：** v2.5.1

## 功能

- 划词搜索：选中文本后弹出悬浮工具栏
- 自定义搜索引擎：支持 `%s`、`{keyword}`、`{searchTerms}` 等多种 URL 占位符格式
- 拖拽链接/图片保存
- 预定义六组高亮样式（可自定义）
- 动态添加关键词增量高亮，无闪烁
- 自动高亮默认关闭
- 工具栏手动隐藏
- 可配置显示的搜索引擎
- 可调整按钮顺序
- 可全局开启/关闭高亮功能
- 极致性能优化
